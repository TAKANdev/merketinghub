# MarketingHub

商品・サービスの情報から、次の24時間で実行するマーケティング行動案を作るWebアプリのMVPです。

## 現在できること

- 商品・サービス名、説明、ターゲット、目標、発信先を入力
- 24時間の時間帯別アクションプランを生成
- SNS投稿文のたたき台を作成
- 目標に応じた測定指標を提案
- 生成したプランや投稿文をコピー
- PC・スマートフォン向けのレスポンシブ表示

## 起動方法

1. このリポジトリを開きます。
2. `index.html` をブラウザで開きます。
3. フォームを入力して「24時間プランを作成」を押します。

GitHub Pagesを有効にすると、ブラウザでアクセスできる形でも公開できます。

## 技術構成

- HTML
- CSS
- JavaScript（フレームワーク・ビルド不要）

## 現時点での制限

これは初期プロトタイプです。プランはブラウザ内のルールに基づいて生成され、生成AIや外部の市場データには接続していません。また、SNSへの自動投稿、広告配信、分析データの取得も行いません。実際のAI分析や自動運用を追加する場合は、安全なサーバー側APIと各サービスの認証設定が必要です。APIキーをフロントエンドや公開リポジトリに置かないでください。
