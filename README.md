# MarketingHub

商品・サービスの情報から、次の24時間のマーケティング行動案を作り、AIでウェブ検索付きの市場・競合リサーチを行うWebアプリのプロトタイプです。

## 機能

- 商品・サービス、説明、ターゲット、目標、発信先を入力
- 24時間の時間帯別アクションプランを生成
- SNS投稿文のたたき台と成果指標を提案
- OpenAI Responses API + web search tool による市場・競合調査
- 参照元リンクを表示
- 計画・投稿文のコピー
- PC・スマートフォン向けのレスポンシブ表示
- AI APIを利用できない場合も、ローカルのルールベース計画は表示

## ローカルでの利用

静的ページのプレビューだけなら、`index.html` をブラウザで開けます。24時間プランのローカル生成は動きますが、AIウェブリサーチAPIはサーバー環境が必要です。

## AI分析を有効にする（Vercel）

1. このリポジトリをVercelにインポートしてデプロイします。
2. Vercelプロジェクトの環境変数に `OPENAI_API_KEY` を設定します。
3. 必要に応じて `OPENAI_MODEL` を設定します（未設定時は `gpt-5.1`）。
4. 再デプロイして、フォームからAI分析を実行します。

APIキーはサーバー側の環境変数にのみ保存します。HTML、JavaScript、公開リポジトリにキーを書き込まないでください。APIの利用にはプロバイダー側の利用資格や料金が関係する場合があるため、開始前に利用条件・料金・利用上限を確認してください。

## 技術構成

- HTML / CSS / Vanilla JavaScript
- Vercel Node.js serverless function（`api/analyze.js`）
- OpenAI Responses API のウェブ検索ツール

## 現時点での制限

- AI分析は市場・競合の調査や施策案を提案しますが、結果の正確性や売上を保証しません。重要な判断の前に参照元を確認してください。
- SNSへの自動投稿、広告配信、決済、アクセス解析サービスへの接続はまだありません。
- APIキーが未設定、APIの利用上限、ネットワーク障害などの場合、AI分析は利用できません。ローカルの24時間プランは引き続き利用できます。
